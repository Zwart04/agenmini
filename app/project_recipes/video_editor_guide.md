# Editor video satu klip

Buka **index.html** di Chrome, Chromium, Edge atau Brave. Semua pemrosesan
berlangsung di browser; tidak perlu mengunggah video atau memasang paket.

1. Pilih berkas MP4/WebM melalui **Import video**.
2. Tekan **Play** untuk memutar/jeda. Geser slider untuk mencari waktu.
3. Isi **Start seconds** dan **End seconds** untuk menentukan rentang trim.
4. Ketik **Text overlay**. Teks langsung tampak pada preview.
5. Tekan **Export** dan tunggu perekaman mencapai akhir rentang trim.
6. Klik **Download** untuk menyimpan WebM. **Cancel** atau Escape membatalkan.

Ekspor berjalan secara realtime, maksimum lebar 720 piksel. Audio bergantung
dukungan browser; status menandai fallback tanpa suara. Mendukung satu klip,
trim dan teks; belum mencakup banyak klip, efek atau seluruh fitur CapCut.

HTML, CSS dan JavaScript runtime ditulis model yang dikonfigurasi, dalam
bagian yang diperiksa. Petunjuk ini ditulis oleh pengembang harness agar
sesuai kontrak kontrol, bukan keluaran model atau kode template aplikasi.
Lihat generation.json untuk asal bagian dan hash berkas. Pemeriksaan sumber
tidak menggantikan pengujian nyata di browser; panduan ini tidak menyatakan
aplikasi hasil generasi baru sudah lulus uji browser.
