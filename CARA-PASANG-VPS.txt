AGEN MINI 0.10.1 — UBUNTU/DEBIAN, TANPA OLLAMA

PASANG BARU ATAU PERBAIKI PEMASANG VERSI LAMA
Jalankan sebagai root pada VPS milik Anda:
  cd /root
  curl -fL https://github.com/Zwart04/agenmini/releases/latest/download/pasang-vps.sh -o pasang-vps.sh
  curl -fL https://github.com/Zwart04/agenmini/releases/latest/download/pasang-vps.sha256 -o pasang-vps.sha256
  sha256sum -c pasang-vps.sha256 && bash pasang-vps.sh

Alternatif ZIP: unggah dan ekstrak agenmini-vps.zip, masuk ke folder hasil
 ekstrak, lalu sha256sum -c pasang-vps.sha256 && bash pasang-vps.sh.
Pemasang menyiapkan Docker dan dependensi. Ikuti pilihan sandi, swap,
koneksi AI serta isi awal. Buka TCP 443 di firewall penyedia VPS.
Buka https://IP-VPS. Instalasi lama mempertahankan sandi, .env, data
 dan model. Jangan hapus instalasi lama sebelum update.

UPDATE
  agen update
Tunggu proses selesai, lalu muat ulang browser. Jika updater lama rusak,
gunakan perintah pemasang di atas. Pada versi 0.9.0, placeholder versi
 di skrip download gateway menyebabkan 404; bukan cache model rusak.
Unduh pemasang rilis baru, jangan menggunakan ulang skrip 0.9.0.
Backup kode dibuat di /opt/agenmini/data/backup/install-*/code.tar.gz.
Rollback kode tidak otomatis menurunkan skema database.

PENGATURAN
Pengaturan > Koneksi: provider OAuth/API, provider gratis atau GGUF lokal.
Harness Agen Mini mengadaptasi inti DeepSeek dalam Python, tanpa memasang
CLI tambahan. Runtime DeepSeek asli dan CLI lain tetap pilihan opsional;
dependensinya diunduh hanya ketika dipilih. Lihat docs/HARNESSES.md.
Model kecil tetap memiliki batas kemampuan; pemeriksaan sintaks bukan
bukti semua interaksi aplikasi sudah bekerja.
Chat > Panel kerja: lihat draf/kode, edit, preview offline dan log alat.
Preview dirender komputer pengguna. Browser otomatis agen tetap opsional.
Chat > Dengan izin/Akses penuh: pilih kebijakan alat. Runtime eksternal
memiliki izin sendiri. Pilih model chat; Telegram: /model.

REMOVE
Lihat rencana penghapusan: agen uninstall --all --dry-run
Hapus program, simpan data: agen uninstall --yes
Hapus seluruh data/model/kredensial: agen uninstall --all --yes
Perintah terakhir permanen; backup dahulu. Docker dan aplikasi lain tetap ada.
Panduan lengkap: README.md dan UNINSTALL.md pada Zwart04/agenmini.
