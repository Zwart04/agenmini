AGEN MINI 0.3.2 — VPS UBUNTU/DEBIAN, TANPA OLLAMA

PASANG BARU / UPDATE VERSI LAMA
1. Ekstrak agenmini-vps.zip di komputer, unggah pasang-vps.sh ke /root VPS.
2. Jalankan sebagai root: bash /root/pasang-vps.sh
3. Buka port TCP 443 di firewall penyedia VPS, buka https://IP-VPS.
   Kata sandi baru ditampilkan pemasang. Instalasi lama memakai sandi lama.
   Reset jika lupa: agen sandi
4. Koneksi > AI: pilih 9router/API, tambahkan provider dengan API key
   atau OAuth, kemudian pilih model. API key router dibuat otomatis.
   Tidak perlu dashboard atau tunnel terpisah. Kuota provider tetap diperlukan.
5. Alternatif: pilih Lokal tanpa Ollama. Supervisor memasang llama.cpp
   dan merekomendasikan model Q4 sesuai hardware. Pilih model pada kartu lalu tunggu unduhannya. Tunggu muat pertama selesai.
   VPS 4 GB RAM disarankan untuk lokal; mode API lebih ringan (2 GB disarankan).

MENU
Workspace: karakter bot, tugas aktif, antrean dan log hasil/alat.
Pengaturan > Skill: anti-slop, verifikasi, pemecahan masalah dan desain bawaan; tambah/edit prosedur atau impor Markdown. Ini bukan pelatihan bobot model.
Koneksi > MCP: Agen Local sudah tersedia tanpa akun. Untuk GitHub gunakan preset; isi URL/token atau perintah stdio, temukan alat dan pilih izin.
GitHub/email: sambungkan MCP milik layanan yang Anda pilih dengan kredensialnya.
MCP stdio perlu executable terpasang di container; HTTP lebih mudah untuk VPS.
Pengaturan > Update: cek rilis, instal, atau aktifkan update otomatis harian.
Update menunggu model tidak sibuk, memeriksa SHA256, dan membuat backup.
OAuth tertentu perlu menyalin URL callback lengkap dari browser komputer Anda.

PERINTAH

PERBAIKAN MODEL VERSI LAMA
Jangan hapus /opt/agenmini/data atau .env. Pasang versi ini di atas versi lama.
Pemasang mempertahankan pilihan model. Cache GGUF lama dipakai ulang jika SHA256 cocok.
Status Siap diperiksa melalui server, bukan hanya nama pilihan tersimpan.
Jika gagal, buka Koneksi > AI > Log model lokal; perintah agen supervisor-log tersedia.

MODEL PER BOT
Workspace > Tim bot > Ubah > Mesin bot dan Model khusus > Simpan.
Provider/kunci dikelola bersama di Koneksi. Bot lokal memakai satu model aktif.
FreeLLMAPI: pilih di Koneksi > AI, tunggu layanan aktif, tambahkan provider dan pilih model.

PEMULIHAN GALAT UPDATER LAMA
Jika agen update berakhir dengan command not found setelah memperbarui kode:
versi baru mungkin sudah tersalin, tetapi skrip lama terpotong karena ditimpa saat berjalan.
Versi 0.3.2 mengganti skrip secara atomik dan sudah diuji saat caller masih aktif.
Untuk melewati updater lama, jalankan sebagai root:
cd /root
curl -fL https://github.com/Zwart04/agenmini/releases/download/v0.3.2/pasang-vps.sh -o pasang-vps.sh
curl -fL https://github.com/Zwart04/agenmini/releases/download/v0.3.2/pasang-vps.sha256 -o pasang-vps.sha256
sha256sum -c pasang-vps.sha256 && bash pasang-vps.sh
Setelah TERPASANG, muat ulang browser; jangan hapus data atau .env.
