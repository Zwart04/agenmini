Sebelum mulai.

Bisa. Pilih sumber AI, provider dan model dari Pengaturan. Anda juga bisa memilih model per percakapan dan bot. Kunci API tidak ditanam di website ini.

Paket Linux menyediakan ikon aplikasi dan perintah agenmini. Antarmukanya dibuka di browser lokal, tanpa Electron. Windows menyediakan installer dan ZIP portable dengan agenmini.cmd. Keduanya memakai data serta pengaturan yang sama untuk pengguna tersebut.

Tidak untuk API online. Bobot model tidak ada di paket aplikasi. Desktop dapat terhubung ke endpoint llama.cpp/Ollama yang sudah berjalan melalui API langsung. Unduhan dan pengelolaan model otomatis tersedia pada pemasangan VPS dengan supervisor.

Agen Mini gratis dengan lisensi GPL-3.0-or-later untuk karya aslinya. Layanan model bisa memiliki biaya dan kuota sendiri. Provider serta komponen pihak ketiga mempertahankan lisensi dan merek masing-masing.
