Working software, checked beyond syntax.

Qwen3.5 0.8B and DeepSeek Coder 1.3B supplied runtime code across multiple attempts. The harness split work into smaller parts, checked behavior, requested repairs, and assembled accepted source.

A clear scope. Measured output.

Import, playback, seeking, trim, text, cancellation and WebM download were checked. A 5-second input trimmed to seconds 1–3 produced a 1.956-second export with text and audio.

This is a combined local-model result with single-clip editing. It does not demonstrate a one-shot 1B generation or the complete CapCut feature set.
